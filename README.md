# Ping Logger

A Python script that pings a target server and logs the latency to a file with timestamps.

## What it does
- Pings a target (e.g., 8.8.8.8 or google.com)
- Records the latency in milliseconds
- Saves results to `ping_log.txt` with date and time

## How to run
python3 ping.py

## Built with
- Python 3
- Ubuntu 22.04 (VirtualBox)
